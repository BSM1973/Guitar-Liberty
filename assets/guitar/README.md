# Guitar Liberty — Clean Guitar Multisamples

Place six legally owned/recorded mono WAV samples in `assets/guitar/clean/`:

- string-1.wav — high E open string (E4 / MIDI 64)
- string-2.wav — B open string (B3 / MIDI 59)
- string-3.wav — G open string (G3 / MIDI 55)
- string-4.wav — D open string (D3 / MIDI 50)
- string-5.wav — A open string (A2 / MIDI 45)
- string-6.wav — low E open string (E2 / MIDI 40)

Recommended recording: clean DI electric guitar, 48 kHz / 24-bit WAV, 2–4 seconds, no reverb/delay, consistent medium pick velocity.

The playback engine pitch-shifts each open-string sample to the requested fret. Missing samples automatically use the synthesized fallback voice.
